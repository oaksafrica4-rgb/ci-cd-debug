# DevOps Interview Broken Project

This project is intentionally broken for a mock DevOps technical interview.

## Expected behavior

The application should run in Docker and respond to:

GET http://localhost:8080/health

Expected response:

{"status":"healthy"}

## Interview instructions

1. Diagnose the problems before changing files.
2. Explain your reasoning as you troubleshoot.
3. Fix the issues.
4. Verify the application works.
5. Check the CI workflow as part of your investigation.

Do not reveal or search for an answer key until you have completed your own troubleshooting.
